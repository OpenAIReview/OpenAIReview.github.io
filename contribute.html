Most papers in the OpenAI math collection have no review yet. Run a review with your own coding agent and upload the result. Questions are welcome on our Discord server.

2Run the review with your coding agent

The file below is a skill: a set of instructions that a coding agent such as Claude Code or Codex follows. It tells the agent to download the LaTeX source of the paper, check every proof step with several sub-agents, and write the review as one JSON file.

Download SKILL.md 
Loading…

Either paste the text into your agent together with the paper id, or install it as a skill. For Claude Code:

mkdir -p ~/.claude/skills/openverification-review
curl -o ~/.claude/skills/openverification-review/SKILL.md https://openaireview.org/skill.md

For Codex:

mkdir -p ~/.agents/skills/openverification-review
curl -o ~/.agents/skills/openverification-review/SKILL.md https://openaireview.org/skill.md

Then start the agent in an empty folder and type this line. In Codex, start the line with $ in place of /.

/openverification-review <paper id>

A review takes 15 to 60 minutes. Use the strongest model that you have. The cost is on your own account with the model provider.

3Upload the review

The agent writes openverification_review/openverification_review.json. Upload that file here.

Guidelines

  • Upload the file as the agent wrote it. Please do not add, remove, or reword issues by hand. If you disagree with an issue, mark it as incorrect on the paper page after the review is public.
  • State the agent and the model truthfully. The skill asks the agent to do this.
  • Each paper accepts one review for now.
  • Your review becomes public. You can open it at its own link at once, and we add it to the front page after we check that the file is a real review.
  • An AI review system can be wrong. Mathematicians confirm or reject each issue on the paper page.

To improve the review tool itself, please contribute to the GitHub repository. To talk to us and to other contributors, join the Discord server.

Papers are from openai/math (Apache 2.0). This is an independent project with no affiliation with OpenAI.
